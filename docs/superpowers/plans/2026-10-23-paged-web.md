# Paged Web App (Plan 2 of 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playable browser game on top of the Plan 1 engine: world map, concept panel, live incident screen (map, inspector, toolboxes, clues, pager) and debrief. It runs locally with `pnpm dev`, and a GitHub Pages workflow is ready for when the repo is published.

**Architecture:** `apps/web` is a Vite + React + TypeScript single-page app with hash routing (so it works on GitHub Pages with no server config). Scenario YAML is bundled at build time via `import.meta.glob` and parsed with `@paged/scenarios`. The engine runs in the browser: a 100 ms interval ticks `Simulation` `speed` times and re-renders from `snapshot()`. Pure logic (progress/unlocks/mastery, graph layout, debrief verdicts, pager text, routing) lives in plain TS modules with Vitest tests. React components stay thin.

**Tech Stack:** React 18, Vite, `@xyflow/react` (architecture map), `uplot` (charts), Vitest, Playwright (one end-to-end smoke test), GitHub Actions (Pages deploy).

**Spec:** `docs/superpowers/specs/2026-10-23-paged-design.md` (§5 game design, §7 persistence, §8–9 web testing/CI). Engine API: `packages/engine/src/index.ts`.

## Global Constraints

- No backend. Progress lives in localStorage under `paged:v1`. Every access is in try/catch, and the game works with storage unavailable.
- Hash routing only (`#/`, `#/concepts`, `#/incident/<id>`, `#/debrief/<id>`). Vite `base: './'`.
- Click-driven UI, no terminal (spec §1 non-goals).
- Stars: ★ win, ★★ with a required design fix, ★★★ also efficient with no clues. Use `scoreRun` from the engine; never re-implement it.
- Unlocks: the first world is always open. Every other world opens when all first-world incidents have ≥1★. Within a world, incident N opens when N−1 has ≥1★.
- Mastery: per concept, the count of distinct incidents tagged with it and won with ≥2★, capped at 4.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Intentional deviations from the spec:**
- Plain React state instead of Zustand (one hook owns the simulation; no global store needed yet).
- Debrief verdicts (helped / neutral / hurt) come from comparing error-budget burn in the 15 s before an action took effect with the 30 s after.

## Review Focus

1. **localStorage unavailable or corrupt.** Expected: the game loads with empty progress and saving silently no-ops. Pinned in Task 2.
2. **Direct navigation to a locked incident or to a debrief with no run in memory** (refresh on `#/debrief/x`). Expected: redirect to the world map, no crash. Pinned in Task 6 (App guards).
3. **Rejected actions** (wrong target kind, still pending, incident over). Expected: a visible toast with the engine's reason, and no state change. Pinned in Task 5 (toast) and covered by the engine's tests.
4. **Worlds with no scenarios yet** (Twitter … Ticketmaster in v1). Expected: shown as "Coming soon", never unlock-blocking, no crash in mastery/unlock math. Pinned in Task 2.
5. **Leaving an incident mid-run** (navigate away, then come back). Expected: the interval is cleared on unmount, and a fresh run starts on return. Pinned in Task 4 (the hook cleans up its interval).

### Task 2: Progress, unlocks and mastery
**Files:** `src/progress.ts`, `src/progress.test.ts`
**Interfaces (produces):** `Progress = { stars: Record<string, Stars>; sound: boolean }`, `STORAGE_KEY = 'paged:v1'`, `emptyProgress()`, `loadProgress(storage?)`, `saveProgress(p, storage?)`, `recordStars(p, id, stars): Progress` (keeps best), `isWorldUnlocked(c, p, worldId)`, `isIncidentUnlocked(c, p, scenarioId)`, `conceptMastery(c, p): Map<string, number>`.

**Tests:**
```ts
import { describe, expect, it } from 'vitest';
import { content } from './content';
import { conceptMastery, emptyProgress, isIncidentUnlocked, isWorldUnlocked, loadProgress, recordStars, saveProgress, STORAGE_KEY } from './progress';

const memory = () => { const m = new Map<string, string>(); return { getItem: (k: string) => m.get(k) ?? null, setItem: (k: string, v: string) => void m.set(k, v) }; };

describe('progress', () => {
  it('keeps the best stars', () => {
    let p = recordStars(emptyProgress(), 'launch-day', 2);
    p = recordStars(p, 'launch-day', 1);
    expect(p.stars['launch-day']).toBe(2);
  });
  it('unlocks incidents in order and other worlds after the tutorial', () => {
    let p = emptyProgress();
    expect(isIncidentUnlocked(content, p, 'launch-day')).toBe(true);
    expect(isIncidentUnlocked(content, p, 'read-heavy')).toBe(false);
    expect(isWorldUnlocked(content, p, 'twitter')).toBe(false);
    p = recordStars(p, 'launch-day', 1);
    expect(isIncidentUnlocked(content, p, 'read-heavy')).toBe(true);
    p = recordStars(recordStars(p, 'read-heavy', 1), 'viral-link', 1);
    expect(isWorldUnlocked(content, p, 'twitter')).toBe(true);
    expect(isIncidentUnlocked(content, p, 'nope')).toBe(false);
  });
  it('mastery counts incidents won with 2+ stars, capped at 4', () => {
    let p = recordStars(emptyProgress(), 'launch-day', 1);
    expect(conceptMastery(content, p).get('horizontal-scaling')).toBe(0);
    p = recordStars(p, 'launch-day', 2);
    const m = conceptMastery(content, p);
    expect(m.get('horizontal-scaling')).toBe(1);
    expect(m.get('caching')).toBe(0);
    expect(m.size).toBe(content.catalog.concepts.length);
  });
  it('round-trips through storage and survives bad storage', () => {
    const s = memory();
    saveProgress(recordStars(emptyProgress(), 'launch-day', 3), s);
    expect(loadProgress(s).stars['launch-day']).toBe(3);
    s.setItem(STORAGE_KEY, '{not json');
    expect(loadProgress(s)).toEqual(emptyProgress());
    const throwing = { getItem: () => { throw new Error('denied'); }, setItem: () => { throw new Error('denied'); } };
    expect(loadProgress(throwing)).toEqual(emptyProgress());
    expect(() => saveProgress(emptyProgress(), throwing)).not.toThrow();
    expect(loadProgress(null)).toEqual(emptyProgress());
  });
});
```

### Task 3: Graph layout and debrief verdicts
**Files:** `src/game/layout.ts`, `src/game/debrief.ts`, tests alongside.
**Interfaces (produces):**
- `layoutGraph(ids: string[], edges: EdgeSpec[]): Map<string, {x:number;y:number}>`: column = longest path from a source (× `COL_W = 240`), rows centred (× `ROW_H = 130`).
- `type Verdict = 'helped'|'neutral'|'hurt'`, `classifyActions(log: ActionLogEntry[], budget: Series, labelOf: (a: ActionId) => string): ActionVerdict[]` with `ActionVerdict = { t; label; target; verdict; reason }`. Only `status === 'effective'` entries are classified. Burn rate = budget drop per second; before window `[t−15, t]`, after window `[t, t+30]`. Helped if after < 0.7·before − 0.01; hurt if after > 1.3·before + 0.01; neutral otherwise, or when either window has < 2 points.

**Tests:**
```ts
// layout.test.ts
import { describe, expect, it } from 'vitest';
import { COL_W, layoutGraph, ROW_H } from './layout';
describe('layoutGraph', () => {
  it('places callers left of callees and centres siblings', () => {
    const pos = layoutGraph(['db', 'lb', 'api', 'cache'], [
      { from: 'lb', to: 'api' }, { from: 'api', to: 'db' }, { from: 'api', to: 'cache' }, { from: 'cache', to: 'db' },
    ]);
    expect(pos.get('lb')).toEqual({ x: 0, y: 0 });
    expect(pos.get('api')).toEqual({ x: COL_W, y: 0 });
    expect(pos.get('cache')).toEqual({ x: 2 * COL_W, y: 0 });
    expect(pos.get('db')).toEqual({ x: 3 * COL_W, y: 0 });
  });
  it('stacks nodes in the same column', () => {
    const pos = layoutGraph(['a', 'b', 'c'], [{ from: 'a', to: 'b' }, { from: 'a', to: 'c' }]);
    expect(pos.get('b')).toEqual({ x: COL_W, y: -ROW_H / 2 });
    expect(pos.get('c')).toEqual({ x: COL_W, y: ROW_H / 2 });
  });
});
// debrief.test.ts
import { describe, expect, it } from 'vitest';
import { classifyActions } from './debrief';
const series = (f: (t: number) => number) => { const t = Array.from({ length: 120 }, (_, i) => i + 1); return { t, v: t.map(f) }; };
const at = (t: number) => ({ t, request: { action: 'add-cache' as const, target: 'db' }, status: 'effective' as const });
describe('classifyActions', () => {
  it('helped when burn drops', () => {
    const budget = series((t) => (t < 40 ? 120 - t : 80));
    expect(classifyActions([at(40)], budget, () => 'Add cache')[0]).toMatchObject({ verdict: 'helped', label: 'Add cache', target: 'db' });
  });
  it('hurt when burn rises', () => {
    const budget = series((t) => (t < 40 ? 120 - 0.1 * (t) : 116 - (t - 40)));
    expect(classifyActions([at(40)], budget, () => 'x')[0]!.verdict).toBe('hurt');
  });
  it('neutral when nothing changes or data is missing, and ignores scheduled entries', () => {
    const budget = series(() => 120);
    expect(classifyActions([at(40)], budget, () => 'x')[0]!.verdict).toBe('neutral');
    expect(classifyActions([at(500)], budget, () => 'x')[0]!.verdict).toBe('neutral');
    expect(classifyActions([{ ...at(40), status: 'scheduled' }], budget, () => 'x')).toEqual([]);
  });
});
```

### Task 4: Pager text and the incident loop hook
**Files:** `src/game/pager.ts` (+ test), `src/game/useIncident.ts`
**Interfaces (produces):**
- `pageText(snap: SimSnapshot, slo: SloSpec): string`: if availability is below the SLO, `"Error rate N% (SLO allows M%)"`, otherwise `"p99 latency Xms > Yms SLO"`. `beep(): void` plays a WebAudio double beep and never throws.
- `useIncident(scenario, onDone)` returns `{ snap, speed, setSpeed, apply, cluesUsed, revealClue, sim }`. `speed: 0|1|2|4` (0 = paused, the initial state). A 100 ms interval calls `sim.tick(speed)`. When the outcome stops being `running`, it calls `onDone({ scenarioId, outcome, stars, sim, cluesUsed })` once, with `stars` from `scoreRun`. The interval is cleared on unmount and on speed change.

**Tests (pager.test.ts):**
```ts
import { describe, expect, it } from 'vitest';
import { pageText } from './pager';
const snap = (availability: number, worstP99Ms: number) => ({ stats: { availability, worstP99Ms } }) as never;
describe('pageText', () => {
  it('reports errors first, then latency', () => {
    expect(pageText(snap(0.58, 3000), { availability: 99.9, p99Ms: 800 })).toBe('Error rate 42% (SLO allows 0.1%)');
    expect(pageText(snap(1, 2345.6), { availability: 99.9, p99Ms: 800 })).toBe('p99 latency 2346ms > 800ms SLO');
  });
});
```

### Task 5: UI components
**Files:** `src/components/{ArchitectureMap,LineChart,Inspector,TopBar,Toolbox,Stars}.tsx`, `src/styles.css`
**Behaviour contract:**
- `ArchitectureMap({ snap, selected, pendingTargets, onNodeClick })`: React Flow, positions from `layoutGraph`, not draggable, `fitView`. Each node has `data-testid="node-<id>"` and shows the kind icon, label, instances, RPS, a utilization bar, and badges 🔥 (utilization ≥ 1 or errors > 5%), ❄️ (cache hit < 50%), ⏳ (pending action). Health colours come from `snap.nodes[].health`. Edges are animated when traffic flows, their width scales with log(RPS) of the callee, and their colour follows the callee's health.
- `LineChart({ series, title, format, markers? })`: uPlot, time on the x axis in sim seconds (`time: false`), resizes via ResizeObserver, draws vertical marker lines at `markers` times.
- `Inspector({ sim, snap, nodeId })`: tabs Metrics (rps, p99, errorRate, utilization, plus hitRatio for caches), Logs (that node's logs plus global ones, newest first), Traces (the last 8 traces that touch the node, rendered as a span waterfall).
- `TopBar({ snap, scenario, page, speed, setSpeed })`: page banner, clock `mm:ss`, speed buttons `⏸ 1x 2x 4x` (accessible names "Pause", "1x", "2x", "4x"), availability vs SLO, error budget bar, users online, $/h.
- `Toolbox({ scenario, selected, onSelect, params, setParams, onClue, cluesUsed, toast })`: Mitigate and Fix-design card groups. A card's accessible name starts with the action label. The selected card shows a param editor (scale `delta`, shed-load `percent`, rate-limit `rps`, autoscaling `targetUtilization`, retry policy `maxRetries`/`backoff`/`jitter`) and the hint "Now click a component on the map". A clue button reveals the next clue and warns that it costs ★★★. The toast area shows the last apply result.
- `Stars({ n })` renders ★/☆ ×3.

**Verify:** `pnpm --filter @paged/web typecheck` and `build`. These are visual components; they get exercised by Task 7's smoke test.

### Task 6: Screens and app wiring
**Files:** `src/screens/{WorldMap,Concepts,Incident,Debrief}.tsx`, `src/App.tsx`, `src/main.tsx`
**Behaviour contract:**
- **WorldMap:** the title "Paged" and a tagline; links to Concepts and a sound toggle. One card per world with its emoji, title and description. Incidents are listed as links (accessible name = title) with difficulty and best stars, plus a 🔒 when locked. Worlds with no incidents show "Coming soon"; locked worlds explain how to unlock them.
- **Concepts:** one card per concept with ●○ mastery dots, the explainer, and links to the incidents that train it.
- **Incident:** first a briefing overlay (title, stage, briefing, SLO, a "Start shift" button). Then the TopBar, the map, the inspector and the toolbox. Applying an action means selecting a card, then clicking a node: `sim.apply({action, target, params})`, and the toast shows `"<Label> scheduled on <node label> · ready in Ns"` or the rejection reason. On the first unhealthy tick, set the page text and `beep()` if sound is on. When the hook reports done, record the stars and navigate to the debrief.
- **Debrief:** heading "Incident resolved" or "Incident lost", stars, timeline charts (availability %, error budget) with action markers, a "Your actions" list with verdicts, What happened, The lesson, In the real world, an **Interview Moment** card with a "Show model answer" toggle, sources, concept chips, and buttons Retry / Next incident (when unlocked) / World map.
- **App guards:** an incident route that's locked or unknown goes to the map. A debrief route without a matching run in memory goes to the map. Retry remounts the Incident with a new `key`.

**Verify:** `pnpm --filter @paged/web build`; then the manual check in Task 7.

```ts
import { expect, test } from '@playwright/test';
test('play the tutorial incident to a win', async ({ page }) => {
  await page.goto('/');
  await page.getByRole('link', { name: /Launch day/ }).click();
  await page.getByRole('button', { name: 'Start shift' }).click();
  await page.getByRole('button', { name: /^Autoscaling/ }).click();

```
Expected dynamics: autoscaling lands at ~11 s and adds 1 instance pre-spike, the 4× spike at 20 s triggers about 6 more (ready ~37 s), the SLO holds from ~37 s, and the win comes at ~97 s sim time, about 25 s wall-clock at 4×.
